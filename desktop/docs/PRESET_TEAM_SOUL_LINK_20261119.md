# 队伍与御魂预设联动（2026-11-19）

启用原来的“切换预设队伍”后，OAS 会定位指定的分组和队伍，先点击该队伍的一键预设御魂，再确认同一队伍。组号和队号仍沿用原配置，不再需要分别填写御魂分组。

## 行为

- 队伍预设开启：队伍及其保存的御魂绑定执行，独立御魂的数字和名称配置不再参与，也不再为这些配置额外进入式神录。
- 队伍预设关闭：原来的独立御魂流程继续生效。
- 队伍预设优先于锁定阵容，避免锁队后游戏自动开打而跳过御魂应用。
- 原通用战斗和 BattleWait 的预设入口共用一套流程；后者取消“配置超时仍直接点准备”的旧处理。
- 支持战斗准备面板和副本队伍预设快捷面板。目标按钮只在选中队伍所在行搜索，不会寻找相邻队伍的御魂按钮。
- 保留滚动定位及任意正整数编号。御魂按钮缺失、遮罩、未知确认框、明确装配失败或队伍不足五人时停止确认出战。
- 御魂配置必须先在游戏里保存在该队伍中；此功能应用已保存的方案，不计算新配装。
- 常见任务的独立御魂入口增加条件判断。麒麟和阴界之门按当次分支判断，道馆按其动态队伍预设开关判断。

## 验证

- 32 项联动检查通过，包含真实面板三行按钮定位、遮罩、错行、确认顺序、装备失败、两套战斗入口、旧配置兼容和锁队优先级。
- 47 项原滚动选队回归通过，覆盖高组号/队号、列表到底、空队伍及既有任务入口。
- 29 个任务入口经语法树还原对比，除独立御魂入口条件外原任务逻辑一致。
- 真实面板样本来自空闲 MuMu 0 的觉醒副本。入库样本已去掉账号和聊天区域。
- 完整实战尚未验收：界面核对期间误触游戏“自动”导致一次自动启动，随后 ADB 离线；已调用 MuMu 官方关闭应用接口，最后核对实例处于关闭状态。没有在此后继续发送游戏点击，也未宣称新联动已经跑完整场战斗。
