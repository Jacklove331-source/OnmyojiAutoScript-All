## 回退与备份

默认 engine 为 auto，模型存在即启用新版。需要使用旧版时，在 `config/ocr_engine.json` 写入：

```json
{"engine": "legacy"}
```

停止并重新启动对应账号后生效；改回 `{"engine":"auto"}` 可恢复新版。进程环境变量 `OAS_OCR_ENGINE=legacy` 优先于此文件。显式传入旧版 rec_model_path 的调用仍遵循原参数。
