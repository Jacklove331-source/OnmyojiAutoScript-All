# OAS 任务日程表（2026-11-14）

OASX 左侧新增「日程表」，随当前账号切换。每日、本周视图自动同步，每 5 秒刷新；点击任务名可打开原有任务配置。绿色勾选表示 OAS 有明确成功结束的执行记录，延期、报错、取消、只有返回值而缺少完成证据的执行不会勾选。

金色标签表示勾玉来源，蓝色标签表示蓝票来源。「可能」「兑换」「购买」区分条件奖励和花费资源的项目；神秘商店购买蓝票会消耗勾玉，不算勾玉收入。标签受账号启用的子项目影响，不承诺实际到账数量。「只看勾玉 / 蓝票」筛选便于优先处理相关任务。

按北京时间自然日（00:00）和周一开始的自然周展示，不改变游戏或 OAS 原有重置、执行时间。每日任务按当天勾选，周常按本周勾选；可显示未启用任务。历史完成记录保留在 `log/task_calendar/calendar.sqlite3`，重启保留，账号隔离。

接入点：`script.py` 的任务运行上下文，`Config.task_delay(success=...)` 的完成信号，以及使用自定义下次时间的任务终点标记。先记录运行，成功结束且有完成信号才写 completed；记录系统故障只记录警告，不中断原自动化。原 AI 自愈流程保持原有判断。

只读接口：`GET /calendar/{config_name}`，可选 `week=YYYY-MM-DD`，禁止缓存。只读取配置、翻译和完成流水，不连接设备、不启动游戏任务。命令 `toolkit/python.exe -X utf8 -B dev_tools/task_calendar_cli.py oas1 --import-logs` 可导入近七天日志：必须同一次 Scheduler Start/End 之间有对应 success=True 且无 ERROR/CRITICAL；确定性去重，不根据 NextRun 推断完成。
