# 工作台 UI 参考与借鉴

工作台是**离线单文件页**（`module/server/web/workbench/index.html`），不引外网 CDN、不跑构建。
下面是我这次重排时真正看过的参考，以及"抄了哪一点"——只抄信息结构、密度和质感做法，不抄代码。

## 1. 阴阳师官网（视觉基调）

- 链接：https://yys.163.com/
- 借鉴：墨黑底 + 宣纸米白 + 描金线 + 朱漆点缀的配色关系；标题用宋/楷类衬线，正文用黑体；金色只做细线和小面积强调，不做大面积渐变。
- 落到页面：`--ink/--paper/--gold/--red` 四组变量；侧栏深墨底 + 金发丝线；区块标题左侧朱红竖条；按钮主色用朱漆，不做荧光色。

## 2. Ant Design · Table（表格与分页）

- 链接：https://ant.design/components/table-cn
- 借鉴：表头吸顶、点表头排序、右下角分页器（首页/上一页/页码/下一页/末页）、数字右对齐。
- 落到页面：御魂表由后端分页（`offset/limit/q/set/slot`，每页 50/100/200），避免一次拉 3547 条；表格外层滚动容器内表头 sticky；分数/号位/品质/等级用等宽数字列。

## 3. shadcn/ui · Table（克制的表面层级）

- 链接：https://ui.shadcn.com/docs/components/table
- 借鉴：卡片只用一层细边框 + 极浅阴影，不堆叠圆角与彩色块；用留白和 1px 分隔线区分层级。
- 落到页面：`.card`/`.sub-block` 的边界处理；表格斑马纹只做到 hover 浅米色；徽标（tag）小、密、低饱和。

## 4. daisyUI · Card（卡片密度）

- 链接：https://daisyui.com/components/card/
- 借鉴：指标卡"小标题 + 大数字 + 一行说明"的三段式；卡片高度紧凑、可自动换行铺满。
- 落到页面：概览/监控/资产/数据源都用 `.kpi` 三段式卡片；窗口变窄时自动 2 列 → 1 列，不用媒体查询写死每张卡。

## 5. MAA 桌面端 / 文档（高密度工具的排布）

- 链接：https://github.com/MaaAssistantArknights/MaaAssistantArknights
- 借鉴：左侧固定导航按"常用 → 进阶"分组，右侧一屏内尽量多给可操作信息；每块都有明确的空态/失败提示，不白屏。
- 落到页面：五组左侧导航（总览/御魂/式神/养成/数据）；所有数据面板统一"加载中 / 空（带原因和建议）/ 失败（带重试）"三态；顶部状态条常驻档案、御魂、式神、待办、数据源与更新时间。

## 自查清单（这次落地的约束）

- 无外网请求：页面里没有 `src="http..."`，也没有 `@import url(...)`；字体只用系统字体。
- 原 13 个 hash 锚全部保留：`#ov #mon #soul-sec #panel-sec #ht-sec #act-sec #roster-sec #asset-sec #shard-sec #guild-sec #profiles-sec #tasks-sec #speed-sec`。
- 720px 以下：导航变顶部横向滑动条，卡片/详情双栏变单栏，表格隐藏"属性明细/标签/备注/路径"等次要列，保留关键列与操作。
- 所有按钮点击都有反馈：变更类按钮出 toast（成功/失败），查询类按钮改行内提示或直接刷新内容。
- 藏宝阁（cbg）相关内容未新增任何菜单或面板。
