**融合的定义（三条硬标准）**
1. 数据由 OAS 自己读（不启动平安志进程、界面不出现"平安志"三个字）；
2. 功能出现在 OAS 自己的导航里（网页 `/workbench/ui` + OASX 桌面页），不是外链；
3. 每条能力都有可跑的自检，数字可复现。

## 三、架构（四层，文件级落点）

```
① 数据层  tasks/Workbench/ingest/
   paz_db.py        只读打开平安志 sqlite（连接 + 表探测）
   paz_extra.py     42 表的业务读法（inventory/guild/todos/rule_versions/snapshots…）
   paz_catalog.py   资料库 JSON + 目录包（bounty/cosmetics/damage/realm-cards）
   paz_snapshot.py  采集快照 JSON（sourcePayload → 结构化）

② 算法层  tasks/Workbench/
   engine.py        规则引擎（评分 Σ权重×(1+手数) / 准入 / 目录）
   features.py      面板、速度线、头尾、碎片矩阵、总览聚合
   analyze/panel_opt.py  束搜索配装（面板计算/提升）
   compare.py       两个历史版本差异（新增，9/9 自检）

③ 接口层  module/server/workbench_router.py
   /workbench/overview|souls|todos|panel/optimize|headtail|speed-preview
   /workbench/paz/{summary,shikigami,bounty,groups,damage,cosmetics,tasks,icon}
   /workbench/simulate/{options,{kind}}   （新增，未启用界面）
   /workbench/compare?older=&newer=        （新增）

④ 界面层
   网页：module/server/web/workbench/index.html（/workbench/ui）
   桌面：_oasx_src/OASX-0.3.2/lib/views/layout/desktop.dart + overview_assets.dart
        （托管总览）；工作台页 lib/views/workbench/workbench_view.dart
```
